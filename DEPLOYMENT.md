# Deploy PromptForge AI on GitHub + Streamlit Community Cloud

These steps produce a **live app**. The ZIP itself is not deployed; you need a GitHub account, a Streamlit account (sign in), and a Groq API key for AI generation.

## 1. Confirm local operation

From the extracted project folder in VS Code PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pytest -q
python -m streamlit run app.py
```

Verify http://localhost:8501 opens and that Prompt Lab shows a preview. Test a real generation with a working Groq API key.

## 2. Push code to GitHub

Create a **new empty public repository** named `promptforge-ai` at https://github.com/new. Don't initialize with a README (this project already has one).

```powershell
git init
git branch -M main
git add .
git status
git commit -m "Build PromptForge AI prompt engineering studio"
git remote add origin https://github.com/YOUR_USERNAME/promptforge-ai.git
git push -u origin main
```

Replace `YOUR_USERNAME`. You may need to authenticate with Git Credential Manager or SSH. If the remote repository already has commits, reconcile history instead of force-pushing.

**Critical:** Before committing, check `git status` and make sure `.env`, `.streamlit/secrets.toml`, and `.venv` are **NOT** staged. They are ignored by the provided `.gitignore`.

## 3. Create a Streamlit Community Cloud app

1. Sign in to https://share.streamlit.io/.
2. Click **Create app** and select **Yup, I have an app** (labels may change).
3. Choose the GitHub repo `YOUR_USERNAME/promptforge-ai` and the `main` branch.
4. Set the **main file path** to `app.py`.
5. In **Advanced settings**, select **Python 3.12**.
6. Click **Deploy**. The platform installs `requirements.txt` and starts the app.

**Groq key choices**:

- **Safer for public demos:** leave Streamlit Cloud secrets blank, and tell users to obtain a key and enter it in the password-masked sidebar field. The key is stored only in their live app session. The provider sees prompts sent via its API.
- **Convenient private/testing demo:** add `GROQ_API_KEY = "YOUR_REAL_KEY"` to the Streamlit Cloud **Secrets** field in Advanced settings. Visitors then use your quota, so this is **not** recommended for unrestricted public access. Never paste secrets into GitHub or public messages.

After deployment, Streamlit shows a URL similar to `https://your-project-name.streamlit.app`. The exact URL is generated by the host; we cannot preassign it from this ZIP.

## 4. Verify the live site

- Confirm it opens in a private/incognito browser window.
- Generate a simple prompt response with a real key.
- Try A/B comparison and the Optimizer.
- Upload `data/sample_evaluation.csv` and evaluate it.
- Confirm no credentials appear in the GitHub repository.

## 5. Troubleshooting

| Problem | Solution |
| --- | --- |
| `ModuleNotFoundError` | Reinstall with `pip install -r requirements.txt` and confirm Python environment. |
| `401` from Groq | Check the API key (no quotes/spaces) and key permissions. |
| `403` from Groq | Your account may lack permission for the selected model; try the other model. |
| `404` from Groq | Provider may have changed available models; see https://console.groq.com/docs/models. |
| `429` from Groq | You've hit a request/token quota. Wait or check your limits at https://console.groq.com/docs/rate-limits. |
| Site works but no answers | Provide a valid key using the sidebar or Cloud secrets. |
| Deployment failed | Check Cloud logs, file path `app.py`, branch `main`, and `requirements.txt`. |

## 6. Future production improvements

For a larger, publicly shared deployment with a host-managed key, add authenticated users, durable server-side per-user rate limiting, centralized observability, provider quota protection, and human-reviewed evaluations. These are intentionally out of scope for this free educational portfolio app.

Official Streamlit deployment docs: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy
